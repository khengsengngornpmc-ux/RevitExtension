CamboBIM Revit 2024 User Guide

Quick onboarding, license setup, tool summary, and support information.

1) Quick Start (For End Users)

  1. Open Revit and go to tab CamboBIM.
  2. Click LICENSE LOGIN in panel Account.
  3. Enter your username and password from your CamboBIM admin.
  4. After successful login, check License expires and Remaining.
  5. Use tool buttons in panel Tools (CAD2MODEL, QS TOOLS, LINKSHEET, etc.).
If login fails, contact admin and provide your account email + machine name shown in the error.

2) Account Panel (Right Side)

These buttons are next to each other in the Account panel.

ABOUT ME Shows product version and support contacts.
LICENSE LOGIN Login, check expiry, and change password.
USER GUIDE Opens this full HTML guideline window.

3) License Duration Calendar (For Admin)

License duration is controlled by CamboBIM Google Sheet, not by end users in Revit.

  1. Open Google Sheet license file.
  2. Use menu CamboBIM License > License Expiry Calendar.
  3. Select user, pick expiry date/time, then click Set Expiry.
  4. Deploy new Apps Script version if script changed.

Required config file on user PC

File: C:\ProgramData\CamboBIM\online-license.config.json

  • enabled must be true
  • server_url must be your Apps Script /exec URL
  • product_code must match allowed_products in Users sheet

6) Troubleshooting

  • License activation failed / Invalid JSON: usually wrong Apps Script deployment URL or old deployment version.
  • User not found: check Users.username in Google Sheet.
  • Invalid username or password: regenerate SHA-256 hash and update password_hash.
  • Seat limit reached: increase max_seats or release existing session.
  • User Guide button not visible: redeploy latest add-in and restart Revit.
